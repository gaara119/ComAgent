# 提交版界面与目录整理

本轮将默认入口切换为 React 与 Ant Design 工作台，继续使用原 FastAPI、共享协议、SQL、RAG、澄清状态与跨源模块。前端地址仍为 `http://127.0.0.1:8501/`，API 为 `http://127.0.0.1:8000/`。

## 清理范围

造数器、已完成的一次性题库修改脚本、旧审核交互 HTML、旧打包脚本、独立 P1 实验与部分历史生成调用已从当前工作目录移出。共81个清单项（含目录、文件和旧交付 ZIP），实际路径记录在 `cleanup-manifest.json`。原件放在仓库外、本地工作区内的 `交付/提交版整理备份-20261016/`，不推送 GitHub。该备份包含清理前未提交文件和差异，方便恢复。

保留当前活动题库及 current.json、各次审核落地记录、manifest 引用的原始题库、两道 gold 正式版本、必要原始结果和阶段报告。没有修改业务数据、人工结论、题库答案或索引内容，没有删除 Docker 数据卷。

`ui/app.py` 与少量旧维护脚本仍被回归测试或重建工具依赖，因此保留兼容。主入口不会启动旧 Streamlit。`eval/experiments/after_d2_01_03/data` 与少量 runtime_eval 文件仍被新版题库或专项评测依赖，属于已生成数据及评测执行器，不是重新造数入口。

## 历史链接

历史报告保留当时文字和成绩。指向已移出审核页面、造数脚本的旧相对链接不会全部有效；按清理清单在本地归档中恢复，不据此改写历史证据或重新填写审核。当前 README 和运行说明只指向保留的运行入口与记录。

## 验证边界

新前端的代理、浏览器交互和响应式测试使用受控测试 API，模拟结果不会被称为真实 DeepSeek 或数据库成绩。项目回归另行记录。首轮旧路由测试没有显式注入模型，意外触发2次DeepSeek调用；原请求与响应、usage单独保留，不计为本轮业务评测。已修正过时的路由测试并改用传输层阻断，后续回归不得发出真实模型请求。不运行保留集，不把界面整理写成 D5 冻结或正式全量评测完成。

仍存在的较新业务专项失败与正式评测缺项见 `eval/reports/screenshot-acceptance/按截图逐条验收报告.md`。本轮不顺手改变其业务语义和 gold。
