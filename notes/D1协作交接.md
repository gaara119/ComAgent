## 3. 本机服务、端口和重启

| 服务 | 默认入口 | 当前使用 |
|---|---|---|
| Streamlit | http://127.0.0.1:8501 | 数据库和指定文档共用页面 |
| FastAPI | http://127.0.0.1:8000/docs | 共用 `/api/chat`，辅助 `/health` 与文档 API |
| PostgreSQL | 127.0.0.1:55432 | Compose 项目 `comagent-d1`、只读 `qa_reader` |

`127.0.0.1` 指运行服务的当前电脑。另一台电脑不能用自己的回环地址访问 A 电脑服务；D1 推荐每台电脑独立准备环境，不把尚未配置的跨电脑网络当成已联调。

`start_demo.ps1` 复用健康项目 API；API 未运行且端口空闲时隐藏启动，并把该次启动的日志与 PID 写入 `.runtime`。Streamlit 在当前终端运行，`Ctrl+C` 停止该页面；API 保持运行。现有端口被占用时脚本提示，不停止陌生进程。已有服务时直接打开页面；另起演示可使用 `-ApiPort 8001 -UiPort 8502`。

修改 `.env`、共享配置或运行代码后要重启自己的 API；健康检查不表示旧进程自动读取新设置。停止后台进程前，核对端口 PID 与本人项目的启动方式，不根据旧 PID 文件停止不明进程。服务无法连接时先看 `.runtime` 日志和 Compose 状态，保留数据库卷。

## 4. A/B 共用接口摘要

共用入口是 `POST /api/chat`，输入 `session_id`、`message`、`scope`，返回 `AnswerEnvelope`。D1 的 `scope.route` 显式选择 `sql` 或 `doc`；SQL 使用 `db_id=chinook`，文档使用恰好一个清单中的 `doc_id`。HTTP 200 仍需核对业务 `status`。

- SQL 返回实际执行的 `sql`、原始结果 `table` 和真实 `steps`；单表约束、200 行展示上限和 5 秒数据库超时有效。
- 文档返回实际答案与证据，`evidence_id` 对应 `[E编号]`，`doc_id` 必须等于指定文档，原文及页码来自索引而非模型编写。
- **当前工程引用页码从 1 起，表示 PDF 物理页，封面计页。** OHR 原始 0 起页索引仅在标注转换时加 1，前端不再加 1。早期计划示意的 0 起协议已由主任务修订说明。
- bbox 是可可靠映射的实际文字块联合区域；没有可靠坐标保持 `null`。当前页面显示原页和原文，不把完整原页显示说成逐字高亮。
- 共享设置、LLM、schema 和 trace 由 A 维护，B 复用；UI 只通过 HTTP 调用 API。完整签名、状态与字段见 [B接口交接](E:/中国电子杯-赛题八/system/notes/B接口交接.md)。

`qa_agent/schemas.py` 当前内容哈希会在最终验收记录中保存。最终合并后用下面的只读命令核对，不把某次中途版本的 SHA 当成永久协议版本。

```powershell
Get-FileHash -LiteralPath 'qa_agent/schemas.py' -Algorithm SHA256
git rev-parse HEAD
```

A/B当前实现和联调已使用同一契约，共享字段与页码的实现已经验证。后续协议改动按方案由两人同步，不新增书面签字或审批步骤。
