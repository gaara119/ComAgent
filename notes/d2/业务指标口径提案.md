# D2 业务指标口径提案 与共同审核记录

本提案用于制作项目自编的 2–3 页指标手册。四项口径已获用户代表 A 和 B 共同确认；D2仅登记定义，没有启用D3完整澄清或口径切换。SQL 已在现有只读 Chinook 快照实际执行；数据库未导入、重建或写入。

以下四项及短语区分已经得到用户代表 A 和 B 的明确共同确认：

1. **销售额**：发票粒度用 `SUM(invoice.total)`；曲目或艺术家粒度用明细 `SUM(unit_price * quantity)`。JOIN 发票与明细后不能重复累加发票总额。
2. **客单价**：拟明确命名为“平均每张发票金额”，采用 `AVG(invoice.total)`；“平均每位购买客户金额”另起名称，不当作同一指标。
3. **复购客户**：指定期间内发票数量至少 2 张的客户。日期字段 `invoice_date`，期间采用左闭右开；没有期间时不悄悄补全。发票记录不等于已付款证据。
4. **热门曲目**：沿用总计划的购买数量默认；销售额与歌单收录数是可选口径。拟保留附录“客户谁买得最多”的金额定义；缺查询对象的“谁买得最多”不自动套同一个全局默认。

通用约定：客户所在地 `customer.country` 与账单地址 `invoice.billing_country` 保留各自含义；金额仅称数据库金额单位；空 SUM/AVG 保留 NULL，零分母保留 NULL 并说明；并列排序使用稳定 ID。
