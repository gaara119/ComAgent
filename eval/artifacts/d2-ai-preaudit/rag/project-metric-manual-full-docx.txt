[paragraph; style=Title] Chinook 业务指标口径手册
[paragraph; style=Subtitle] 项目自编规则文档 D2 版本
[paragraph; style=Normal] 本手册明确销售额、平均每张发票金额、期间内复购客户和热门曲目的计算方式，用于团队复核 SQL 的字段、粒度和边界。四项口径已由用户代表 A 和 B 共同确认。
[paragraph; style=Heading 1] 范围与通用约定
[paragraph; style=Normal] 数据来自现有 Chinook 1.4.5 PostgreSQL 快照；已核对可用发票日期范围为2021年1月1日至2025年12月22日。本手册不补写缺失期间，不宣称发票代表成功付款。
[paragraph; style=Normal] 期间统一用 invoice.invoice_date 与左闭右开区间 [开始日, 结束日)。SQL 示例仅以2024年说明过滤写法；具体问答应使用用户明确指定的期间。
[paragraph; style=Normal] 客户所在地使用 customer.country；发票账单地址使用 invoice.billing_country。当前快照中的值相等不改变两种地区含义。
[paragraph; style=Normal] 金额仅表示数据库金额单位，不能推断币种。SUM 与 AVG 在无发票记录时保留 NULL；计数无符合项时为0；零分母返回 NULL 并解释不可计算。
[paragraph; style=Heading 1] 指标对应关系
[table]
指标全名 | 统计粒度 | 核心表达式
发票销售额 | 发票 | SUM(invoice.total)
平均每张发票金额 | 发票 | AVG(invoice.total)
期间内复购客户数 | 期间内客户 | 发票数至少2张的客户数
热门曲目 | 期间内曲目 | SUM(invoice_line.quantity)
[paragraph; style=Normal] 机器可读规则保存在 data/rules/metric_definitions.json。口径审核与每一道评测题的 gold 人工审核分别记录，互不替代。

[paragraph; style=Heading 1] 四项指标的定义与限制
[paragraph; style=Heading 2] 销售额
[paragraph; style=Normal] 发票层面按 SUM(invoice.total) 汇总；曲目或艺术家层面按 SUM(invoice_line.unit_price * invoice_line.quantity) 汇总，并连接发票日期进行期间过滤。实际快照已只读核对两种全库总额一致。
[paragraph; style=Normal] 汇总发票总额时不能在发票与明细 JOIN 后重复计入同一张发票。无可用发票的 SUM 结果为 NULL；不得悄悄当作已发生的零销售。
[paragraph; style=Heading 2] 平均每张发票金额
[paragraph; style=Normal] 本项目将客单价主口径写全为平均每张发票金额，表达式 AVG(invoice.total)，每张发票权重相同。
[paragraph; style=Normal] 平均每位购买客户金额另命名为 SUM(invoice.total) / COUNT(DISTINCT invoice.customer_id)，不与每张发票平均金额混用。无发票或零分母时保留 NULL。
[paragraph; style=Heading 2] 期间内复购客户数
[paragraph; style=Normal] 在用户指定期间内，按 customer_id 分组，统计发票数量至少2张的客户；输出单位为客户数。
[paragraph; style=Normal] 同一客户跨期各有一张发票，不自动算作单期复购。发票资料不能证明付款、退款或商品使用状态。没有合格客户时返回0。
[paragraph; style=Heading 2] 热门曲目
[paragraph; style=Normal] 曲目最受欢迎沿用总计划的购买数量默认，即 SUM(invoice_line.quantity)。按销售额或按歌单收录数属于明确的备选口径，不能凭当前排名相同而互换。
[paragraph; style=Normal] 附录中的客户谁买得最多保留金额口径；没有查询对象的短语不套同一个全局默认。并列时以 track_id 升序稳定排序。D2登记口径，不提前实现 D3 完整澄清分级或口径切换。
[paragraph; style=Normal] 
[paragraph; style=Heading 1] 已核对的 SQL 示例
[paragraph; style=Normal] 以下示例由项目只读账号在同一快照执行并保存原始结果。这里只列写法和边界，不列测试题的具体答案。允许源资料核对所需的子查询，在线 D2 单表问数的安全边界仍由现有 SQL 校验器执行。
[paragraph; style=Heading 2] 发票销售额
[paragraph; style=Normal] SELECT SUM(total) AS revenue
FROM public.invoice
WHERE invoice_date >= DATE '2024-01-01'
  AND invoice_date < DATE '2025-01-01';
[paragraph; style=Heading 2] 平均每张发票金额
[paragraph; style=Normal] SELECT ROUND(AVG(total), 2) AS average_invoice_amount
FROM public.invoice
WHERE invoice_date >= DATE '2024-01-01'
  AND invoice_date < DATE '2025-01-01';
[paragraph; style=Heading 2] 期间内复购客户数
[paragraph; style=Normal] SELECT COUNT(*) AS repeat_customer_count
FROM (SELECT customer_id FROM public.invoice
 WHERE invoice_date >= DATE '2024-01-01'
   AND invoice_date < DATE '2025-01-01'
 GROUP BY customer_id HAVING COUNT(*) >= 2) AS r;
[paragraph; style=Heading 2] 热门曲目按购买数量
[paragraph; style=Normal] SELECT track_id, SUM(quantity) AS purchased_quantity
FROM public.invoice_line
WHERE invoice_id IN (SELECT invoice_id FROM public.invoice
 WHERE invoice_date >= DATE '2024-01-01'
   AND invoice_date < DATE '2025-01-01')
GROUP BY track_id
ORDER BY purchased_quantity DESC, track_id ASC LIMIT 5;
