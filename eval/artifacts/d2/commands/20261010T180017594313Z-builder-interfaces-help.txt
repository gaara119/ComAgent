usage: build_value_index.py [-h] [--output OUTPUT] [--catalog CATALOG]
                            [--aliases ALIASES] [--audit AUDIT]
                            [--draft-aliases]
                            [--draft-standard DRAFT_STANDARD]
                            [--no-embeddings]

Build D2 read-only value indexes, or draft aliases for explicit human review.
No dataset/gold inputs are accepted. SQL identifiers come only from the
catalog. The two phases allow inspection before the expensive, shared BGE
batch build.

options:
  -h, --help            show this help message and exit
  --output OUTPUT, --output-dir OUTPUT
  --catalog CATALOG     Read an existing trusted catalog; never builds or
                        imports a database
  --aliases ALIASES
  --audit AUDIT, --audit-output AUDIT
  --draft-aliases
  --draft-standard DRAFT_STANDARD
                        Only draft this actual standard value; repeatable
  --no-embeddings       Preparation/audit only; does not satisfy D2 vector
                        acceptance
