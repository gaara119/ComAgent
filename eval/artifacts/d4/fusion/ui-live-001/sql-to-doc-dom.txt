SELECT a.artist_id, a.name AS artist_name, SUM(il.unit_price * il.quantity) AS sales_amount FROM public.invoice_line AS il JOIN public.track AS t ON t.track_id = il.track_id JOIN public.album AS al ON al.album_id = t.album_id JOIN public.artist AS a ON a.artist_id = al.artist_id GROUP BY a.artist_id, a.name ORDER BY sales_amount DESC, a.artist_id ASC LIMIT 1

公开背景
Iron Maiden（铁娘子乐队）是英国重金属乐队，由贝斯手及主要创作者 Steve Harris 于1975年在伦敦东部的 Leyton 组建。
乐队是英国重金属新浪潮的重要代表。其音乐和歌词涉及历史、文学、战争、神话及科幻等题材。
同名首张录音室专辑于1980年发行；1982年的 The Number of the Beast 是其早期重要作品。这里介绍的是公开音乐背景，不包含 Chinook 销售排名或当代巡演收入。
