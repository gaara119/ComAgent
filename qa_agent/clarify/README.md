# 语义校验与多轮澄清

`service.py` 组织结构化理解、业务规则检查和会话恢复。`state.py` 保存版本化意图，应用条件补丁，管理澄清卡片与状态提交。

- **L0**：条件明确，可以继续处理。
- **L1**：使用有效授权默认，并说明采用的假设。
- **L2**：关键歧义影响结果，暂停业务查询并请求用户选择。

`rules.py` 与 `data/rules/` 提供业务规则；`sql_guard.py` 等模块检查已确认的期间和筛选条件是否进入 SQL。续问修改条件时，保留未修改条件，使受影响的旧计划和结果失效，再执行查询。澄清卡片包含版本，旧卡片不能覆盖新的会话状态。

这一层检查系统是否理解了用户的问题；SQL 语法与只读权限仍由 SQL 模块独立检查。
