# 跨源计划与执行

复用现有 SQL 和文档工具，在步骤之间传递实际结果，统一返回答案和两边的证据。

- `planner.py`：实现受约束的 SQL→文档、文档→SQL 流程。前者将实际查询得到的实体 ID 与文档登记关系对齐；后者检索指标定义，核对来源和计算口径，再交给 SQL 模块执行。
- `composed.py`：处理有界的组合步骤，包括用户会话正文、数据库和已登记文档；计划必须符合允许的数据源与工具范围。
- `plan_contract.py`、`obligations.py`：检查计划及最终输出是否覆盖用户要求，避免局部工具成功却遗漏任务。

没有对应文档、缺少指标定义或证据不足时，保留已有真实结果并说明缺口。文档里的 SQL 或指令不会绕过查询校验。
