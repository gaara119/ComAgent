# 要素识别与有据改写

将用户表达与数据库中的真实值、实体及字段角色对齐，供 SQL 生成和任务规划使用。

- `value_index.py`：读取值索引与已审核别名；候选存在不代表允许自动绑定。
- `linker.py`：按需使用精确值、别名、拼音、模糊、向量和模型裁决召回候选；自动绑定另设置信度与分差要求。
- `ownership.py`：检查值属于哪个字段角色，避免把条件绑定到错误对象。
- `grounded_rewrite.py`：依据当前问题、正文和真实续问形成有来源的问题要素；原问题保留为权威输入。
- `rewrite.py`：应用有依据的局部改写，保留修改来源。

要素识别不批准业务默认，不代替用户确认歧义，也不能从实体名称自行推导用户想做的任务。
